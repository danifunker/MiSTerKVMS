# Icon credits

The app icon features **MiSTer-Kun**, the MiSTer FPGA project's mascot.

- Original design by GitHub user **HeWhoisRed**, given to the MiSTer community to be used and remixed freely; attribution appreciated.
- Remastered artwork: [baxysquare/mister_kun](https://github.com/baxysquare/mister_kun). `misterkun.svg` here is the full-colour version as shipped with [mrext Remote](https://github.com/wizzomafizzo/mrext), with the colour-palette swatches removed.

The monitor, keyboard and mouse around it are drawn by `make_icon.py`.

MiSTer-Kun is also drawn on the iPhone app's demo test pattern
(`core/assets/misterkun.png`, rendered from `misterkun.svg`), and credited in
each app's About (on the iPhone: Settings → About).
